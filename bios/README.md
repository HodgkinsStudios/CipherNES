# Famicom Disk System BIOS

The Famicom Disk System BIOS is **not included** with CipherNES.

To use FDS images, place your legally obtained 8 KiB BIOS at:

```text
bios/disksys.rom
```

The BIOS must be exactly 8192 bytes. The file is ignored by Git and is never copied into source or release archives by the packaging script.
